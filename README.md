# Todo Application 

A simple Todo application built with Java.

## Features

* Add a Todo
* View Todos
* Mark a Todo as completed
* Delete a Todo
* Exit the application

## Technologies

* Java
* Scanner
* Arrays
* Switch statement

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Run `Main.java`.
4. Choose an option from the menu.

## Note

This is a beginner-level project created to practice basic Java concepts.
